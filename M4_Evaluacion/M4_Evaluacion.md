# Proyecto: Smart Task
## Evaluación del módulo 4: Fundamentos de Programación en Java
### Necesidad
Aplicación para gestionar tareas diarias desde la consola,  tal que pueda expandirse fácilmente a futuro y sirva como base de buenas prácticas en desarrollo en Java.
### Objetivo
Desarrollar una aplicación de consola en Java llamada SmartTask, que permita 

- gestionar tareas personales (agregar, listar, marcar como completadas y eliminar), 
    - aplicando progresivamente los fundamentos del lenguaje Java,
        - algoritmos, 
        - estructuras de control, 
        - orientación a objetos, 
        - principios de diseño, 
        - pruebas unitarias y 
        - documentación técnica. 

El proyecto debe estructurarse de forma modular y escalable, aplicando buenas prácticas, permitiendo su posterior evolución hacia interfaces gráficas o web.
### Requerimientos
Uso del lenguaje Java y su entorno de desarrollo (JDK, Eclipse o VSCode).
- Aplicación ejecutable desde consola (.jar).
- Capacidad de:
    - Agregar tareas con nombre y prioridad.
    - Listar tareas activas y completadas.
    - Marcar tareas como completadas.
    - Eliminar tareas por ID.
- Implementación con:
    - Clases e instancias.
    - Encapsulamiento.
    - Herencia y polimorfismo.
    - Interfaces y clases abstractas.
    - Buenas prácticas de codificación y documentación (JavaDoc).
    - Pruebas unitarias con JUnit5.
### Aspectos a alidar
- Correcta aplicación de conceptos de programación orientada a objetos.
- Uso adecuado de estructuras de control y sintaxis Java.
- Estructura modular, mantenible y escalable del código.
- Buenas prácticas: convenciones de nombres, documentación, comentarios
y estilo.
- Funcionamiento de todas las funcionalidades requeridas desde consola.
- Pruebas unitarias funcionales y cobertura mínima del 80%.
- Código limpio, documentado, sin errores de compilación o warnings
innecesarios.
### Entregables
- **Código fuente del proyecto SmartTask completo**.
- Ejecutable .jar funcional desde consola.
- Documento con JavaDoc generado.
- Archivo .zip con pruebas JUnit.
- Capturas de pantalla del funcionamiento del programa.
- Informe de cobertura de código (opcional).
### Portafolio
Incorporar este proyecto en el portafolio personal destacando:
- Uso de buenas prácticas y POO en Java.
- Documentación técnica profesional.
- Aplicación funcional multiplataforma desde consola.
- Ejemplo de pruebas unitarias automatizadas con JUnit.
